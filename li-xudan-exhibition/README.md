# 地图上的人 · 李旭旦互动数字展

以水墨山水、人物叙事、交互年表与概念地图，呈现李旭旦的求知、求实与育人之路。

## 运行

这是纯静态网站，无需安装依赖或构建。直接打开 `index.html`，或在本目录运行：

```sh
python3 -m http.server 8000
```

随后访问 `http://localhost:8000`。

## 内容

- `index.html`：展览页面与资料来源。
- `styles.css`：水墨视觉、响应式布局与动画。
- `app.js`：时间轴、地图图层、创作说明与动画开关。
- `assets/`：展览山水图像。
- `creation-notes.md`：可下载的创作说明。

进入页面时默认播放动态效果，可在顶部暂停。地图用于解释人地关系的基本视角，不对应真实地理位置；人物叙述的参考资料可在页面中查阅。

## 发布

适用于 GitHub Pages。从仓库默认分支的根目录发布即可；`.nojekyll` 用于直接发布静态文件。所有站内资源均采用相对路径，可部署在项目子路径。
