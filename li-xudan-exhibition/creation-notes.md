# 地图上的人 李旭旦互动数字展

## 作品概述

本作品围绕江苏江阴籍地理学家、地理教育家李旭旦，呈现其求知、研究与育人经历。通过水墨意象、可点选年表与人地关系图层互动，将公开史料转化为可阅读、可探索、可追溯的数字展览。

作品形式：响应式互动网站。网页动画由 HTML、CSS 与 JavaScript 实现。图片与代码均随作品提供，字体使用设备系统字体，外部资料链接需要联网阅读。

## 史实与艺术表达

1. 人物年份、经历与研究内容，以文末列出的中科院地理所、大学、学术期刊及出版社资料为依据。
2. 李旭旦出生年份使用1911年；不使用存在不同记载的具体出生月日。使用“1936年赴英、1939年归国”，不单列有表述差异的授位年份。
3. 1952年的学校名称使用“南京师范学院”。正文保留中科院资料的“1952年后”表述。
4. 著作名称使用出版社书目确认的《人文地理学概说》，不使用二手资料中常见的《人文地理学概论》。该书为李旭旦主编。
5. 页面标题、章节标题、叙述与结语均为创作者表达，不冒充人物原话。两幅插画为山水意象，不冒充旧照片、手稿、历史现场或科学家的原作。
6. 互动图层为人地关系的概念示意，不对应真实地理位置，不复原特定研究结果，不包含测绘或实测数据。图层开关控制概念标记和连线；背景绘画始终保留。

## 交互与动画

- 水墨开篇：山水渐显与轻微镜头推移；文字依次进入。
- 卷一“其人”：以求知、求实、育人三个章节介绍人物。
- 卷二“行迹”：点选1911、1936、1939、1947、1952、1985六个节点，查看对应经历与来源。
- 卷三“观地”：切换自然环境、聚落分布、人的活动图层；点选山地、河流、聚落、田地、往来，阅读概念说明。
- 卷四“留痕”：打开权威资料，继续阅读。
- 支持手机与桌面浏览、键盘操作；进入网站时默认开启动画，可使用右上角按钮暂停或恢复。
